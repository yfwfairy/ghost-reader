# 自动播放 & 更多菜单 设计文档

## 概述

在阅读器右上角图标行最右侧新增"更多"按钮，点击弹出菜单，包含「自动播放设置」和「使用说明」两个入口。自动播放实现连续平滑滚动，支持 TXT 和 EPUB 格式，滚到章节底部自动切换下一章。

## 功能结构

### 更多按钮 & 菜单

- **位置**：右上角图标行（沉浸、书签、目录等）最右侧
- **图标**：`more_horiz`（Material Symbols）
- **交互**：点击弹出轻量 popover 菜单

菜单项：
1. **自动播放设置** — 点击后菜单消失，弹出自动播放面板
2. **使用说明** — 点击后菜单消失，弹出使用说明面板

点击菜单外区域关闭菜单。

### 自动播放面板

从更多菜单点击进入，面板样式与现有 ReaderDrawer 风格一致（底部弹出 or 浮层面板）。

#### 面板内容

```
┌─ 自动播放设置 ──────── ✕ ─┐
│                            │
│  自动播放            [开关] │
│                            │
│  ── 开关打开后展开 ──────── │
│                            │
│  速度  ────●────── 中      │
│                            │
│  鼠标移开后滚动      [开关] │
│                            │
└────────────────────────────┘
```

#### 自动播放开关

- **关闭（默认）**：下方调节区域隐藏
- **打开**：展开速度和鼠标控制选项，立即开始滚动

#### 速度滑块

- 5 档：极慢 / 慢 / 中 / 快 / 极快
- 对应 px/frame 速率：约 0.3 / 0.6 / 1.0 / 1.8 / 3.0
- 默认值：中（档位 3）
- 拖动实时生效

#### 鼠标移开后滚动开关

- **关闭（默认）**：无论鼠标在哪，始终自动滚动
- **打开**：鼠标悬停在阅读器内容区时暂停滚动，移开后恢复滚动

## 滚动引擎

### 驱动方式

使用 `requestAnimationFrame` 循环驱动，每帧对滚动容器执行 `scrollTop += delta`。

### TXT 格式

- 滚动目标：`.txt-renderer` 容器的 `scrollTop`
- 章节切换：滚动到 `scrollHeight - clientHeight` 后触发 `chapterNext()`
- 到达最后一章末尾时停止自动播放

### EPUB 格式

- 滚动目标：`.epub-container` 元素的 `scrollTop`
- 章节切换：滚动到底后调用 `rendition.next()`，等待新章节渲染完毕后继续滚动
- 到达最后一章末尾时停止自动播放

### 与键盘快捷键共存

- 自动滚动期间，↑↓ 按键仍正常工作（手动微调位置）
- 手动滚动后自动播放不暂停，从新位置继续滚动
- PageUp/PageDown 同理

### 快捷键

- **空格键**：仅在自动播放已开启时生效
  - 自动播放运行中 → 暂停
  - 自动播放已暂停 → 恢复
  - 自动播放未开启 → 无效果

### 自动播放指示器

- 自动播放运行时，更多按钮旁出现一个小呼吸动画圆点
- 暂停时圆点静止（不消失，表示仍处于自动播放模式）
- 关闭自动播放后圆点消失

### 沉浸模式兼容

- 沉浸模式下自动播放正常运行
- UI 隐藏不影响滚动逻辑
- 空格键在沉浸模式下仍可暂停/恢复

## 使用说明面板

从更多菜单点击进入，面板展示所有操作指引，内容即新手引导（ReaderGuide）的完整集合。

### 内容结构

分区卡片形式展示：

1. **基础操作** — 滚动阅读、翻页
2. **快捷键** — 所有键盘快捷键列表
3. **沉浸模式** — 进入/退出方式
4. **自动播放** — 空格暂停/恢复、更多按钮入口
5. **外观设置** — Ghost 面板使用

### 与设置面板的关系

- **SettingsPanel 删除 Shortcuts tab** — 只保留 Appearance 和 Language
- 快捷键信息完全移至使用说明

## 新手引导更新

ReaderGuide 增加以下内容：

- 空格键：暂停/恢复自动播放（需先在面板中开启）
- 右上角 ⋯ 按钮：自动播放设置、使用说明入口

## 状态管理

### 不持久化到 config 的状态（会话级）

- `autoScrollEnabled: boolean` — 自动播放是否开启
- `autoScrollPaused: boolean` — 是否被空格键或鼠标暂停
- `autoScrollSpeed: number` — 速度档位（1-5）
- `autoScrollPauseOnHover: boolean` — 鼠标移开后滚动开关

每次打开阅读器或切换书籍时重置为默认关闭状态。

### 状态归属

自动播放状态由 ReaderPage 持有（useState），通过 props 或 context 传递给渲染器和面板。

## 组件结构

| 组件 | 职责 |
|------|------|
| `MoreMenu` | 菜单 popover，展示两个菜单项 |
| `AutoScrollPanel` | 自动播放设置面板 |
| `UsageGuidePanel` | 使用说明面板 |
| `useAutoScroll` hook | 核心滚动逻辑（RAF 循环、暂停/恢复、鼠标监听） |

### useAutoScroll hook 接口

```typescript
type UseAutoScrollOptions = {
  enabled: boolean
  speed: number          // 1-5
  pauseOnHover: boolean
  scrollRef: React.RefObject<HTMLElement | null>
  onChapterEnd: () => void  // 滚到底时触发
}

type UseAutoScrollReturn = {
  paused: boolean
  pause: () => void
  resume: () => void
  toggle: () => void     // 空格键用
}
```

## 不做的事

- 不做定时翻页模式（只做连续滚动）
- 不做朗读/TTS
- 不做阅读计时器
- 不持久化自动播放设置到磁盘
- 不做自动播放进度条/时间预估
